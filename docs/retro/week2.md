# 2주차 팀 회고 (KPT)

## 1. 회고 개요

- 팀명: 취업할거조
- 참여자: 최진영, 조성식, 권우리, 강민하
- 목적: 2주차 기능 구현 및 협업 과정에서 좋았던 점과 개선할 점을 공유하고, 다음 주에 적용할 팀 규칙을 정한다.

## 2. 팀원별 KPT

### 최진영

**Keep (계속할 점)**

- 기능별 역할을 적절하게 분담하여 개발을 원활하게 진행함.

**Problem (개선할 점)**

- 팀원 간 구현 상황과 작업 방식에 대한 이해가 부족하여 일부 문제 발생.
- 다른 팀원의 작업 내용을 충분히 파악하지 못한 상태에서 수정 및 테스트가 진행되는 경우가 있음.

**Try (시도할 점)**

- PR 작성 시 수정 사항과 테스트 범위를 명확하게 정리하기.
- 변경된 파일과 주요 구현 내용을 숙지하여 팀원 간 작업 이해도 높이기.

### 조성식

**Keep (계속할 점)**

- 담당한 프로젝트 개발 작업을 꾸준히 진행함.

**Problem (개선할 점)**

- 개인 담당 기능 구현에 집중하면서 다른 팀원의 작업 내용과 구현 방식을 충분히 파악하지 못함.

**Try (시도할 점)**

- 필수 기능 구현 완료 후 통합 테스트를 조기에 진행하기.
- 통합 테스트 과정에서 다른 팀원의 작업 내용을 이해하고 필요한 수정 사항을 함께 확인하기.

### 권우리

**Keep (계속할 점)**

- 목표한 일정에 맞춰 개발 작업을 원활하게 진행함.

**Problem (개선할 점)**

- 구현한 기능의 동작 원리와 구조에 대한 이해가 다소 부족함.
- 기능 구현 과정에서 작업 우선순위를 결정하는 데 아쉬움이 있었음.

**Try (시도할 점)**

- 핵심 기능 구현을 우선적으로 진행하여 개발 효율 높이기.
- 기능 구현과 함께 동작 원리를 최대한 이해하는 방향으로 학습하기.

### 강민하

**Keep (계속할 점)**

- 팀원 간 역할을 명확하게 분담하여 각자 담당한 기능을 원활하게 구현함.

**Problem (개선할 점)**

- 개별 기능 구현에 집중하면서 프로젝트 전체 구조에 대한 이해가 부족함.
- 작성한 코드와 사용한 기술의 내부 동작 원리를 충분히 숙지하지 못함.

**Try (시도할 점)**

- 단순한 코드 작성에 그치지 않고 사용한 기술의 동작 원리를 학습하기.
- 구현 과정에서 주요 기술과 코드의 작동 방식을 직접 찾아보고 이해하는 습관 기르기.

## 3. 공통 회고

### Keep

- 명확한 역할 분담을 바탕으로 각자의 담당 기능을 원활하게 구현함.
- 목표한 개발 일정에 맞춰 프로젝트를 진행함.
- 팀원들이 각자의 역할에 책임감을 가지고 개발에 참여함.

### Problem

- 개별 기능 구현에 집중하면서 다른 팀원의 작업 내용과 구현 방식을 충분히 파악하지 못함.
- 프로젝트 전체 구조와 코드의 동작 원리에 대한 이해가 부족함.
- 작업 변경 사항과 테스트 범위에 대한 공유가 충분하지 않음.
- 통합 테스트 및 기능 간 연동 확인이 상대적으로 늦어질 가능성이 있음.

### Try

- PR 작성 시 주요 변경 사항과 테스트 내용을 명확하게 기록하기.
- 다른 팀원의 PR과 변경된 코드를 확인하여 프로젝트 전체 구조에 대한 이해도 높이기.
- 필수 기능 구현 후 통합 테스트를 조기에 진행하여 연동 문제 확인하기.
- 기능 구현뿐 아니라 사용한 기술과 코드의 동작 원리도 함께 학습하기.
- 핵심 기능을 우선적으로 구현하고 작업 우선순위를 명확하게 설정하기.

## 4. 다음 주 팀 규칙

선정 규칙: PR을 통한 작업 내용 공유 및 통합 테스트 강화하기

### 실천 방법

1. PR 작성 시 주요 변경 사항, 수정된 파일 및 테스트 범위를 명확하게 기록한다.
2. 팀원들은 다른 팀원의 PR을 확인하고 주요 기능과 변경 사항을 파악한다.
3. 필수 기능 구현 후 통합 테스트를 진행하여 기능 간 연동 여부를 확인한다.
4. 테스트 과정에서 발견한 문제와 수정 내용을 팀원들과 공유한다.
5. 주요 기능의 동작 원리와 프로젝트 전체 구조를 이해하며 개발을 진행한다.

### 기대 효과

- 팀원 간 작업 내용 및 프로젝트 구조에 대한 이해도 향상
- 기능 간 충돌 및 연동 오류 조기 발견
- 변경 사항 공유를 통한 협업 효율 향상
- 단순 기능 구현을 넘어 기술적 이해와 문제 해결 역량 강화

## 5. 다음 주 점검 사항

- [ ] 다른 팀원의 작업 내용과 변경된 코드를 확인하였는가?
- [ ] 필수 기능 구현 후 통합 테스트를 진행하였는가?
- [ ] 통합 테스트에서 발견한 문제와 해결 내용을 공유하였는가?
- [ ] 담당 기능의 동작 원리와 프로젝트 전체 구조를 충분히 이해하였는가?
